# Aequora v1 known issues

This file is the human-readable companion to `v1-readiness.ron`. No release-specific v1 RC has
been selected, so this development snapshot makes no GA claim and records no accepted GA defect.

Before an RC, every known issue must have a stable identity, S0-S4 severity, owner, impact,
workaround where applicable, and resolution state in the exact release readiness manifest. Open
S0/S1 or correctness/security-critical defects block GA. An open S2 requires a documented,
non-correctness-critical limitation and a usable workaround.
