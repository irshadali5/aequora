# Certification security and advisory policy

Report suspected conformance bypasses, false capability claims, artifact/signature weaknesses, or
certified implementation vulnerabilities through the repository's private security-reporting
channel. Do not include production credentials or user payloads.

Maintainers triage the affected subject versions, suite versions, features, and environments. A
credible safety issue suspends active records while investigation proceeds; a confirmed issue is
revoked or superseded with a stable reason. The original artifact and certification ID are never
deleted or reused. Remediation requires a new exact-subject artifact and normal trust review.

Runtime compatibility negotiation, authorization, input validation, and deployment preflight
remain mandatory even for active official certifications.
