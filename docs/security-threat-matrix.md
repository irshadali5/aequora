# Security Threat Matrix

This is the maintained Part 27 threat register. The governing design remains
[`sys-arch/27-security-threat-model-abuse-resistance.md`](../sys-arch/27-security-threat-model-abuse-resistance.md).
Each new externally reachable subsystem must add its assets, entry points, abuse cases, controls,
detection, tests, residual risk, and owner here before release.

| Threat | Asset | Entry point / precondition | Mandatory mitigation | Detection | Regression evidence | Residual risk |
|---|---|---|---|---|---|---|
| Cross-tenant identifier probing | Tenant data | Authenticated caller knows another tenant's entity, scope, blob, operation, snapshot, or export ID | Server-derived tenant binding, object authorization, tenant-scoped query, indistinguishable denial | `CrossTenantAttempt`, `cross_tenant_denied_total` | `cross_tenant_resource_matrix`, property test | Timing may not be perfectly indistinguishable |
| Forged identity claims | Identity and authorization | Client supplies tenant, actor, role, scope, priority, or authority | Validate authentication evidence, derive trusted context, authorize typed operation | `AuthenticationFailure`, `AuthorizationDenied` | `authentication_and_tenant_binding` | Compromised trusted identity provider |
| Revoked or lost device | Tenant data and tokens | Device retains old credential | Server-side device-state lookup, reject new sync/operations, revoke sessions, best-effort purge | `DeviceRevokedAttempt` | revoked-device authentication test | Permanently offline cached plaintext |
| Operation replay | Authoritative state | Captured valid request resent | `OperationId`, semantic digest, ledger idempotency, reauthentication | replay/payload mismatch metric | `operation_payload_substitution` and existing ledger contracts | Denial traffic still consumes bounded edge work |
| Payload substitution | Ledger integrity | Same `OperationId`, changed semantics | Tenant/actor/device-bound BLAKE3 semantic digest, reject mismatch | `PayloadSubstitutionRejected` | `operation_payload_substitution` | Canonicalization bugs require regression corpus |
| Compatibility downgrade | Protocol safety | Safety capability stripped or weak version offered | Part 21 `RequiredForSafety`, server minimum, client security floor | `ProtocolDowngradeRejected` | `required_capability_and_protocol_downgrades_fail_closed` | Incorrect capability classification |
| Parser/allocation bomb | Availability | Oversized frame, vector, graph, nesting, or string | Pre-decode and during-decode limits, checked arithmetic, admission before mutation | input-limit metric | boundary-plus-one tests and fuzzers | Parser implementation defects |
| Compression/archive bomb | Availability and host filesystem | Small compressed payload expands massively | Bound compressed bytes, expanded bytes, ratio, entries, paths; no links/devices | unsafe-archive/input metrics | `boundary_plus_one_and_archive_bomb` | Unknown archive parser flaws |
| Archive traversal | Host filesystem | `../`, absolute, Windows path, symlink/hardlink | Validate normalized relative paths and entry type before extraction | unsafe-archive event | archive traversal/link tests | Platform-specific path semantics outside adapter contract |
| SSRF / cloud metadata | Service credentials and private network | Webhook/provider URL controlled by tenant | HTTPS allowlist, hostname and resolved-IP checks, private/link-local block, revalidate connected IP | `SsrfBlocked`, `ssrf_blocked_total` | localhost, RFC1918, IPv6, metadata, redirect, rebinding tests | Compromised approved public destination |
| Webhook replay/impersonation | Provider integrity | Forged or duplicate incoming delivery | Provider signature, bounded timestamp, stable delivery ID, dedupe; IP is never authentication | signature-invalid/provider metrics | provider adapter contract | Provider secret compromise |
| Payment manipulation/replay | Financial state | Client total or duplicate provider event | Server-side amount, signature/reference validation, provider idempotency, reconciliation | payment/security audit | side-effect and provider acceptance tests | Ambiguous provider outage requires reconciliation |
| Job injection/stale worker | Durable workflow state | Arbitrary job kind or expired worker | Registered typed creation, least privilege, fencing token, CAS, bounded retry/fan-out | stale-worker/job metrics | Part 23 contracts | Compromised currently fenced worker within privilege |
| Snapshot swap/replay | Tenant state | Tenant B or old-epoch manifest served to A | Tenant/scope/epoch/root/signature binding and short-lived authorized URL | signature/epoch event | snapshot swap and authority tests | Signing-key compromise |
| Authority rollback/fork | Global integrity | Lower epoch or same checkpoint with different digest | Highest-trusted epoch, fencing, checkpoint comparison, fail closed, no auto-merge | rollback/fork critical event | `authority_epoch_rollback` and authority contracts | Simultaneous compromise of authority and external anchors |
| Admin privilege escalation/replay | Control plane | Weak operator or duplicated destructive request | Private listener, strong auth, typed permission, plan digest, approval separation, `AdminOperationId`, verification, audit | denied/override critical events | Part 24 admin contracts | Colluding authorized approvers |
| Insider/direct DB mutation | Ledger and audit | Privileged human bypasses application | DB role separation, limited runtime/migration/support roles, tamper-evident audit, checkpoints | integrity scan and audit-chain alert | audit/authority adapter contracts | Fully privileged infrastructure insider |
| Secret leakage | Tokens and private keys | Debug, log, diagnostic, audit, API response, crash dump | Non-serializable redacted zeroizing types, classification/sanitization, protected dumps | secret scan and diagnostic validation | secret redaction and Part 15/25 contracts | Secrets already exposed to compromised process memory |
| Blob/upload abuse | Storage and availability | Oversized, cross-tenant, spoofed type, malicious filename | Size/chunk/quota limits, trusted tenant ownership, filename only metadata, private object ACL | upload/quota security event | cross-tenant and boundary tests | Product-specific malware detection is deployment-owned |
| Search/scope cost amplification | Availability and confidentiality | Long query, complex filters, scope explosion, cursor forgery | Typed filters, bounded query/filter/results/scopes, validated cursor/epoch/ownership, cost admission | rate/admission metrics | scope and admission contracts | Authorized expensive workloads within configured budget |
| Diagnostic exfiltration/malware | Secrets and operator workstation | Broad bundle/export or hostile imported bundle | Explicit permission, bounded collection, pre-publication sanitization, encryption/signing policy, sandboxed parser/replay | diagnostic security audit | Part 25 contracts | Authorized operator can access approved evidence |
| Legacy/import poisoning | Authoritative state | Dirty or compromised CDC/import source | Treat as untrusted, typed mapping/domain validation, quarantine, bounded parser, post-cutover write fence | quarantine/legacy critical event | legacy adoption contracts | Incorrect application mapping approved as valid |
| Provider/plugin abuse | Tenant data and side effects | Provider sends hostile data or plugin executes code | Minimal typed provider interfaces, egress control, compile-time features; no dynamic core plugins | provider circuit breaker/events | integration contracts | Compromised compiled dependency |
| Resource-exhaustion/noisy neighbor | Availability | Flood, reconnect storm, slowloris, fake cursor, snapshot/job herd | Edge timeouts/body limits, hierarchical admission, tenant quotas/fairness, durable work, bounded queues | Part 18 telemetry | admission/performance contracts | Unlimited upstream DDoS is a non-goal |
| Supply-chain compromise | Build and release | Malicious crate, build script, macro, CI action | Lockfile, minimal dependencies, review, `cargo deny/audit`, secret scan, pinned CI/toolchain, provenance/SBOM for release | dependency/security CI | release security checklist | New or undisclosed compromise |

Security profiles are configuration postures, not compliance certifications. Deployment controls
(TLS termination, private networks, workload identity, KMS, database roles, object ACLs, malware
scanning, SIEM, DAST, and penetration testing) must supply evidence independently.
